 DriveEasy – Projet de location de véhicules

DriveEasy est un site web permettant de consulter, réserver et gérer des véhicules en ligne.  
Le projet a été réalisé dans le cadre du module de développement web, avec pour objectif de créer une plateforme fonctionnelle connectée à une base de données.  
L’application propose une page d'acceuil avec navbar, barre de recherche, calendrier, notamment une page de réservation, un système simple et une interface rapide d’utilisation.

Prérequis
- XAMPP installé  
- Apache + MySQL activés  
- Navigateur web (Chrome, Edge etc)  
- Git (Pour cloner le projet)

Installation
1. Cloner le dépôt :
git clone https://github.com/assitan001/driveeasy

2. Importer la base de données `driveeasy.sql` dans phpMyAdmin  
3. Lancer Apache et MySQL dans XAMPP  
4. Ouvrir le projet dans le navigateur :
http://localhost/driveeasy/
